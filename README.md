# SmartHP

Интеграция Home Assistant для управления тепловым насосом по цене электричества Nord Pool и по наружной температуре. Подходит к любому тепловому насосу, у которого в Home Assistant есть уставка (number / climate) или контакт блокировки.

*Home Assistant integration that controls a heat pump by Nord Pool electricity price and outdoor temperature. UI languages: English, Русский, Latviešu.*

## Возможности

| Функция | Что делает | Нужная сущность |
|---|---|---|
| Кривая отопления | Температура подачи по 5 точкам (−20…+20 °C), сдвиг, мин./макс., усреднение наружной температуры | уставка насоса |
| Цена электричества | В дешёвые часы подача выше, в дорогие ниже; доли дешёвых/дорогих часов и абсолютные пороги | — (цены Nord Pool встроены) |
| Блокировка насоса | Остановка в дорогие часы с ограничением длительности, паузой и запретом при морозе | контакт блокировки или SG Ready |
| Циркуляционный насос | 3 периода времени, режим «работа/пауза», условие по температуре бойлера, защита от закисания | контакт насоса (необязательно) |
| Дополнительный котёл | Включение по наружной температуре (точка бивалентности) и/или по цене, мин. время работы, остановка насоса на время работы котла | контакт котла |
| ГВС по цене | Разные уставки бойлера для обычных, дешёвых и дорогих часов | уставка ГВС |
| Защита от легионеллы | Еженедельный прогрев бойлера в заданный день и время | уставка ГВС |
| Летний режим | Отопление выключается выше заданной наружной температуры | — |
| Коррекция по помещению | Подача поправляется по отклонению комнатной температуры | датчик в помещении |
| Ночное снижение, отпуск | Снижение подачи по расписанию и на время отъезда | — |
| Излишек солнечной энергии | Повышение подачи и ГВС при избытке PV | датчик мощности |
| SG Ready | Состояния 1–4 на двух контактах | два реле |

Функция и её настройки появляются только если при настройке выбрана её сущность.

## Установка

1. HACS → ⋮ → **Пользовательские репозитории** → `https://github.com/keziksdmitrijs-byte/smartHP`, тип **Integration**. Установите SmartHP и перезапустите Home Assistant.
   Без HACS: скопируйте папку `custom_components/smarthp` в `config/custom_components/` и перезапустите.
2. **Настройки → Устройства и службы → Добавить интеграцию → SmartHP**.
3. Шаг 1 — основные сущности: датчик наружной температуры, зона Nord Pool и НДС, уставка насоса, контакт блокировки.
   Шаг 2 — дополнительные (все необязательны): циркуляционный насос, датчик и уставка бойлера, доп. котёл, датчик в помещении, PV, SG Ready.

Сущности можно поменять позже кнопкой **Настроить** на карточке интеграции.

### Цены Nord Pool

Цены встроены в SmartHP: при настройке выберите ценовую зону (по умолчанию LV) и НДС — интеграция сама загружает цены на сутки вперёд с портала Nord Pool, отдельная интеграция Nord Pool не нужна. Появляется датчик `sensor.smarthp_current_price` (EUR/kWh с НДС). Работают 15-минутные цены.

Если хотите использовать свой датчик (например, с наценкой поставщика), укажите его в поле «Свой датчик цены». Поддерживаются официальная интеграция Nord Pool, Nord Pool из HACS и любые датчики с атрибутами `raw_today` / `today` / `prices_today`.

Абсолютные пороги и порог цены для доп. котла задаются в единицах цены: EUR/kWh для встроенных цен или единицы вашего датчика.

### Уставка насоса

- **Температура подачи** — SmartHP пишет рассчитанную по своей кривой температуру.
- **Только смещение** — SmartHP пишет лишь поправку (цена, помещение, ночь и т. д.), кривая остаётся в самом насосе.

## Панель управления

После установки в боковом меню появляется панель **SmartHP**: состояние, график кривой и все функции с выключателями и настройками.

Ту же панель можно добавить на любую панель Lovelace как карточку:

```yaml
type: custom:smarthp-card
# title: Тепловой насос     # необязательно
# device: SmartHP           # необязательно, если интеграций несколько
```

Готовый пример панели — в файле [`lovelace/smarthp-dashboard.yaml`](lovelace/smarthp-dashboard.yaml).

## Безопасность

- При выключении «Управление включено», выгрузке интеграции и остановке Home Assistant блокировка насоса снимается.
- Блокировка не включается ниже заданной наружной температуры и не длится дольше заданного времени.
- Если датчик наружной температуры недоступен, SmartHP ничего не пишет в уставку.
- Температура антилегионеллы выше ~55 °C обычно требует ТЭНа — проверьте возможности своего насоса.

Интеграция управляет отопительным оборудованием. Проверьте работу на своей системе, прежде чем оставлять её без присмотра.
